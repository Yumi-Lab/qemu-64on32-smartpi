CE QUE CE GATE NE PROUVE PAS
----------------------------
La sonde est NON DESTRUCTIVE : elle installe dans un scratch prive et compare,
elle n'ecrit rien dans le code cache et ne relie aucun TB. Elle prouve que les
octets servis seraient corrects, PAS que l'install chaud destructif (item 3c :
ecriture dans le code cache + tb_reset_jump + tb_link) est correct, ni qu'il
rend la moindre seconde. La correctness reelle reste V4-1G, le juge wall-clock
reste V4-2.
