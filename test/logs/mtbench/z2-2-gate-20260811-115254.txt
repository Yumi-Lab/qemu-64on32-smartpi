CE QUE CA TRANCHE : si le gain WARM est significatif (>= 2.0%) a un N quelconque,
l'argument de fermeture mono-thread ("la traduction n'est pas le goulot") ne tient plus en
multi-thread et la famille de pistes qu'il a fermee (Z2-2 le dit explicitement) doit etre rouverte.
Un gain nul ou negatif CONFIRME l'argument sous une charge qui reecrit son code a chaque tour :
voir le commentaire d'en-tete (le cache ne peut couvrir que le code de demarrage, pas les tours smc).
